# Hiragana & Katakana — Complete beginner Kana charts

**Both Hiragana and Katakana represent sounds**, not meaning. Each has 46 modern basic symbols. Dakuten/handakuten and small-kana combinations represent additional sounds. Unlike Kana, Kanji are meaning-bearing characters, not alphabet letters.

The Romaji column uses common learner Hepburn spelling. In particles, は sounds **wa**, へ sounds **e**, and を sounds **o**, although their kana spellings remain は / へ / を.

## Other essential symbols and spelling

| Item | Meaning |
|---|---|
| っ / ッ | Small tsu doubles the next consonant: がっこう → gakkou |
| ー | Katakana long-vowel mark: スーパー → suupaa (keyboard Romaji) |
| ぁぃぅぇぉ / ァィゥェォ | Small vowels for combinations and foreign sounds |
| ゃゅょ / ャュョ | Small ya/yu/yo, used with other Kana |
| ゎ / ヮ | Small wa (uncommon) |
| ゔ / ヴ | vu (mainly modern loanwords) |
| ゐ / ヰ and ゑ / ヱ | Historical wi/we, not modern everyday spellings |
| 句読点: 。、 | Full stop and comma |
| か + ゛ → が; は + ゜ → ぱ | Voicing and semi-voicing marks |

## How to practise

Run `:JPKanaQuiz` to choose basic, voiced, or combination recognition. For handwriting/stroke order, consult a dedicated textbook; typing practice does not evaluate pen strokes.

## Romaji reminder

Romaji is a learning aid, not a substitute for Kana. Long vowels can also be shown with macrons (e.g. とうきょう → Tōkyō), whereas the local converter uses keyboard-style spellings. For example sentences with Kanji, enter the Kana reading yourself before generating a tentative Romaji suggestion.
